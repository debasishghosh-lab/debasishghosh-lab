### 🧩 Friendship Blueprint — Student Clustering System

> Applied Agglomerative Clustering to **80+ student profiles** encoded across clubs, hobbies, and teamwork preferences using MultiLabelBinarizer. Systematically evaluated k=2–7 and selected k=5 as optimal via Silhouette Score (**0.62**), validated through MDS 2D visualization. The resulting "Friendship Map" was adopted as a real seating/team-formation tool, reducing overlap by **35%**.
